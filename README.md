# Electric City Baptist Church: Website Preview

A proposed redesign of the website for [Electric City Baptist Church](https://electriccitybaptist.com) in Schenectady, NY, made as a gift for the church.

**This is a preview, not the church's official website.** Search engines are asked not to list it.

- 8 pages: Home, About, Beliefs, Plan a Visit, Media, Bible Institute (TTBI), Give, Contact
- Plain HTML, CSS and JavaScript, with no build step
- See `CHURCH-SETUP.md` for connecting Breeze forms and publishing
